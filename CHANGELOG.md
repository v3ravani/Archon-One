# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-07-10
### Added
- First public release of `archon-one`.
- Modern PyPI packaging configuration with `pyproject.toml`.
- Console entry point `archon`.
- Full-featured static code analysis engine.
- 5 detailed modules (Code Metrics, Security Checks, Code Analysis, Contributor Stats, Repository Intelligence).
- Interactive HTML settings viewer.
- Remote Git repository scan command (`archon git`).
