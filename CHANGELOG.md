# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-07-12
### Added
- Comprehensive Knowledge Graph module (`archon graph`).
- Customizable settings under settings dashboard for Knowledge Graph generation.
- Dynamic graph filtering and BFS depth limits based on settings.
- Integrated output directory auto-ignoring in code scanner.
### Removed
- Standalone HTML explorer from deliverables list.

## [0.1.0] - 2026-07-10
### Added
- First public release of `archon-one`.
- Modern PyPI packaging configuration with `pyproject.toml`.
- Console entry point `archon`.
- Full-featured static code analysis engine.
- 5 detailed modules (Code Metrics, Security Checks, Code Analysis, Contributor Stats, Repository Intelligence).
- Interactive HTML settings viewer.
- Remote Git repository scan command (`archon git`).
